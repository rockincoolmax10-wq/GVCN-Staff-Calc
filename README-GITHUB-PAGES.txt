GVCN Staff Format Builder - GitHub Pages deployment

IMPORTANT: Extract this ZIP. Do not upload the ZIP file itself to your repository.

The repository's published root must contain these files side-by-side:
- index.html
- favicon.ico
- gvcn-logo.png
- .nojekyll

For the repository GVCN-Staff-Calc:
1. Open the repository on GitHub.
2. Upload/replace the files above directly in the repository root (not inside another folder).
3. Commit the changes to the branch configured in Settings > Pages.
4. In Settings > Pages, set Build and deployment to Deploy from a branch, choose the published branch (usually main) and /(root), then Save.
5. Wait for the Pages deployment to finish, then open the site URL again.

The project page URL is expected to be:
https://rockincoolmax10-wq.github.io/GVCN-Staff-Calc/

If GitHub Pages is configured to publish /docs instead of /(root), place all four files inside docs/ or change Pages to /(root).
